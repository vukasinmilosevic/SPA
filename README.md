Instrukcije za import notebook-ova u google colab:

Koristeći vaš google nalog, ulogujte se na https://colab.research.google.com/
* Nakon uspešnog login-a, imaćete pred sobom opciju za otvaranje notebook-ova (prozor "Open notebook")
* Među ponuđenim opcijama, izaberite "Github" i unutar textbox-a "Enter a github URL..." unesite link ka ovom projektu: https://github.com/vukasinmilosevic/SPA
* Nakon pretrage kroz ceo SPA repo, biće vam predstavljena lista dostupnih notebook-ova (ispod naziva "Path")
* Izaberite notebook sa predavanja koje želite da pregledate (npr. za predavanje iz 2. tematske celine izaberite notebook pod nazivom "SPA_2_tem_celina.ipynb")
* **Napomena:** Nije obavezan korak, ali zarad čuvanja izmena koje unesete u notebook, dobro je sačuvati kopiju na vašem gDrive-u i raditi na njoj (opcija File -> Save a copy in Drive)
